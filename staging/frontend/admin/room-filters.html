Room Filters

Manage the subheadings and filter options shown on the property listing page.

Add subheading

Create the filter group first. You can then add filter options under it.

Add filter

Select an existing subheading, then define the filter label and the value used by ROOMO search.

Use the property’s stored value: for example wifi, parking, temple, or an exact stay type. Rating values should be numbers such as 4.5.

Edit, reorder, enable, disable, or remove items. Deleting a subheading also deletes its filters.
